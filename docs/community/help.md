# Getting help

## GitHub

### Issues

Report bugs or request features on the [issue tracker](https://github.com/TimeCopilot/foundationforecast/issues).

### Discussions

For general questions and community discussions, use [GitHub Discussions](https://github.com/TimeCopilot/foundationforecast/discussions).

## Related projects

- [TimeCopilot](https://github.com/TimeCopilot/timecopilot) — full forecasting agent with stats, ML, and ensemble models
- [TimeCopilot docs](https://timecopilot.dev) — documentation for the broader ecosystem

## Note

When using Windows, wrap multiprocessing entry points with `if __name__ == "__main__":` to avoid spawn-related errors with heavy model backends.
