### Features

* **Timestral**: The [`Timestral`](https://docs.timecopilot.dev/foundationforecast/api/models/foundation/models/#foundationforecast.models.timestral.Timestral) wrapper supports Mistral's [`Timestral-5M/28M/123M/209M`](https://huggingface.co/collections/mistralai/timestral) checkpoints via `timecopilot-timestral>=0.1.0`. Native known-future covariates (`X_df`), 21 native quantile knots (0.01–0.99) with linear interpolation to arbitrary `level` / `quantiles`, and benchmark-aligned defaults `symmetric_averaging=True` and `clip_nonnegative=True`. See [#67](https://github.com/TimeCopilot/foundationforecast/pull/67).

### Fixes

* **Timestral quantiles**: Map requested levels and quantiles with `resolve_quantile_values` instead of requiring exact native knots. See [#67](https://github.com/TimeCopilot/foundationforecast/pull/67).
