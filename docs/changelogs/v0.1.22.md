### Features

* **Conformal PID control**: New [`PID`](https://docs.timecopilot.dev/foundationforecast/api/core/conformal/#foundationforecast.core.conformal_pid.PID) method for [`ConformalIntervals`](https://docs.timecopilot.dev/foundationforecast/api/core/conformal/#foundationforecast.core.conformal.ConformalIntervals), following [Angelopoulos, Candes & Tibshirani (2023)](https://arxiv.org/abs/2307.16895). Pooled conformal methods guarantee coverage on average but react slowly when the error scale changes; `PID` replays the calibration windows in time order and tracks the error quantile online (quantile tracking plus error integration), so the intervals follow volatility shifts. It works with every model and is a one-line change. See [#102](https://github.com/TimeCopilot/foundationforecast/pull/102).

    ```python
    import pandas as pd

    from foundationforecast import PID, ConformalIntervals, FoundationForecast
    from foundationforecast.models import Chronos

    df = pd.read_csv(
        "https://timecopilot.s3.amazonaws.com/public/data/air_passengers.csv",
        parse_dates=["ds"],
    )

    model = Chronos(
        repo_id="amazon/chronos-bolt-tiny",
        alias="Chronos-Bolt",
        prediction_intervals=ConformalIntervals(n_windows=5, method=PID()),
    )

    ff = FoundationForecast(models=[model])
    fcst = ff.forecast(df=df, h=12, freq="MS", level=[80, 95])
    ```

    On GOOGL daily open prices (2008 to 2014, 80% intervals, Chronos-Bolt one-step forecasts, 250 calibration windows) `PID(symmetric=True)` has a lowest 50-day rolling coverage of 0.68, while `conformal_error` drops to 0.50 (both average about 0.79) and the native Chronos quantiles overcover (0.89). See the new example notebook.

* **`ConformalMethod` base class**: `ConformalIntervals.method` accepts a string (unchanged) or a `ConformalMethod` object, so parameterized methods like `PID` can be passed directly. `PID` and `ConformalMethod` are exported from `foundationforecast`.
* **`PID` options**: asymmetric tails by default (`symmetric=True` for one threshold on the absolute error), `integrate=False` for quantile tracking only, rolling or expanding learning-rate range, and quantile or zero initialization. With `step_size < h` the error at horizon `j` is only used `j` observations after its cutoff. A saturated integrator gives infinite bounds and a `UserWarning`; `ConformalIntervals` rejects `PID()` with too few windows at construction.

* **PID unit and contract tests**: Hand-computed golden values (including delayed feedback), an independent calendar-time oracle, out-of-sample coverage after a variance shift, no future leakage, parameter validation, forecaster integration, and a `test_models.py` contract test.
