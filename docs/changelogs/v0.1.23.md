### Fixes

* **Local checkpoints**: A `repo_id` that is a directory on disk loads for the models that document a local path. `T0` always downloaded `config.json` with `hf_hub_download`, which only accepts a Hub id, so `T0(repo_id="./modelos/t0-alpha")` raised `HFValidationError`. It now reads `config.json` from the directory. TiRex 1.0 parsed a filesystem path as `org/name` before opening weights; a local directory now loads `model.ckpt`. TimesFM, Moirai, Chronos and TimeH2O classify the checkpoint from its name (the last path segment), so a local directory is routed like the Hub id it was copied from. See [#109](https://github.com/TimeCopilot/foundationforecast/pull/109) and [#103](https://github.com/TimeCopilot/foundationforecast/issues/103).

### Tests

* **Local checkpoint contract**: `test_forecast_from_local_checkpoint` runs a one-step forecast from a local snapshot for every model in `tests/models/conftest.py`. Python files are materialized outside the Hugging Face blob cache so dynamic modules such as Tabby can resolve relative imports.
