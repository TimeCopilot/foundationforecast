### Features

* **Tabby**: The [`Tabby`](https://docs.timecopilot.dev/foundationforecast/api/models/foundation/models/#foundationforecast.models.tabby.Tabby) wrapper supports Huawei Paris Noah's Ark Lab's [`paris-noah/Tabby`](https://huggingface.co/paris-noah/Tabby) ([arXiv:2609.13956](https://arxiv.org/abs/2609.13956)), a ~147M prompted patch transformer that emits 99 native quantiles (0.01–0.99) from up to 8,192 observations. The wrapper follows the published inference path: 8,096-step context, `context_mask` and `past_is_pad` passed to the forward, and a `precision` option (`"bf16"` autocast on CUDA by default, `"fp32"` to disable it). The checkpoint loads with `trust_remote_code` and is released under CC BY-NC 4.0. See [#76](https://github.com/TimeCopilot/foundationforecast/pull/76).

### Tests

* **Tabby**: Mocked tests for quantile mapping, context truncation and precision handling, a live test on `paris-noah/Tabby`, and cross-model contract coverage through `tests/models/conftest.py`. See [#76](https://github.com/TimeCopilot/foundationforecast/pull/76).
* **GIFT-Eval replication**: `paris-noah--Tabby` is registered against the official `results/Tabby` entry (MASE 0.688, CRPS 0.4758), with the `m4_weekly/short` subset added to CI. The leaderboard flags that entry `testdata_leakage: Yes` because the prompt was tuned on GIFT-Eval training tasks; the harness verifies the wrapper reproduces the official numbers regardless of that flag. There is no fev-bench entry, since Tabby is univariate and has no official result there. See [#76](https://github.com/TimeCopilot/foundationforecast/pull/76).

### Documentation

* **Tabby family notebook**: [`tabby-family` example notebook](../examples/tabby-family.ipynb) cross-validates Tabby with its published settings on event pageviews, with prediction intervals and executed outputs. See [#76](https://github.com/TimeCopilot/foundationforecast/pull/76).
* **Model hub and README**: Document the Tabby checkpoint, `precision` option, CC BY-NC 4.0 license and `trust_remote_code` requirement; add Tabby to the supported-models table with the Huawei Noah's Ark Lab logo.
