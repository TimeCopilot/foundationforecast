### Features

* **Kumo-Forecast**: The [`Kumo`](https://docs.timecopilot.dev/foundationforecast/api/models/foundation/models/#foundationforecast.models.kumo.Kumo) wrapper supports NVIDIA's [`nvidia/Kumo-Forecast`](https://huggingface.co/nvidia/Kumo-Forecast) ([Kumo-TS](https://github.com/NVIDIA/Kumo-TS)), a ~340M-parameter zero-shot forecaster built on a MOMENT-style T5 encoder with a linear forecasting head. It reads up to 512 observations (shorter series are left-padded and masked, `NaN`s are masked) and predicts 72 steps at once; longer horizons roll forward autoregressively. Weights are loaded through the new inference-only [`timecopilot-kumo-forecast`](https://github.com/TimeCopilot/timecopilot-kumo-forecast) fork. See [#94](https://github.com/TimeCopilot/foundationforecast/pull/94).
* **Point forecasts only**: Kumo has no native quantiles. Requesting `level` or `quantiles` raises a `ValueError` pointing to `prediction_intervals=ConformalIntervals(...)`, which calibrates intervals from cross-validation errors of the point forecast and works as for any other model.
* **`Forecaster.supports_native_quantiles()`**: New capability (default `True`, `False` for `Kumo`) so cross-model quantile tests skip models that need conformal intervals.

### Tests

* **Kumo**: Mocked-model tests in `tests/models/test_kumo.py`, and `Kumo` and `Kumo-CF` (conformal intervals) in the `test_models.py` parametrization. Checked on a Modal A10G with the real checkpoint (53 passed, 6 skipped for native exogenous variables and native quantiles). There is no GIFT-Eval leaderboard entry for Kumo, so no replication job. See [#94](https://github.com/TimeCopilot/foundationforecast/pull/94).

### Documentation

* **Kumo family notebook**: [`kumo-family` example notebook](../examples/kumo-family.ipynb) forecasts with Kumo, shows the error without native quantiles, and adds conformal intervals and cross-validation (coverage on M4 Hourly was 0.865 and 0.941 at 80% and 95%).
* **Model hub and README**: Document the Kumo checkpoint, add it to the supported-models table, the exogenous-variables table and the conformal prediction page, and list the install requirement (`timecopilot-kumo-forecast>=0.1.0`).
