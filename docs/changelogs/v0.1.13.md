### Fixes

* **Chronos-2 CUDA out-of-memory**: Chronos-2 pipelines halve the inference `batch_size` and retry when a batch hits `torch.cuda.OutOfMemoryError`, keeping the smaller size for later batches. Other Chronos pipelines re-raise as before. See [#45](https://github.com/TimeCopilot/foundationforecast/pull/45).
* **Chronos-2 LoRA adapters with `peft>=0.21`**: Loading a local LoRA checkpoint allowlists the `chronos` package, which newer `peft` releases require before importing an adapter's base model class. See [#62](https://github.com/TimeCopilot/foundationforecast/pull/62).

### Tests

* **Chronos**: Cover the CUDA out-of-memory batch back-off, and run the LoRA save-and-reuse test instead of skipping it ([#45](https://github.com/TimeCopilot/foundationforecast/pull/45), [#62](https://github.com/TimeCopilot/foundationforecast/pull/62)).

### Documentation

* **Zensical**: The docs build with [Zensical](https://zensical.org/) and are published with the rest of the TimeCopilot docs at [docs.timecopilot.dev](https://docs.timecopilot.dev/foundationforecast/). See [#51](https://github.com/TimeCopilot/foundationforecast/pull/51) and [#54](https://github.com/TimeCopilot/foundationforecast/pull/54).
* **API reference**: `FoundationForecast` and every model now list `forecast`, `cross_validation`, `detect_anomalies` and `plot`, with new docstrings on all three forecasting methods. Internal helpers (`validate_input`, `_foundation_forecast`) are no longer shown. See [#60](https://github.com/TimeCopilot/foundationforecast/pull/60).
* **Experiments**: New docs section with the [GIFT-Eval](https://docs.timecopilot.dev/foundationforecast/experiments/gift-eval/) writeup (16 models replicated for $37, every model with an official submission within 2% of its leaderboard MASE/CRPS) and [fev-bench](https://docs.timecopilot.dev/foundationforecast/experiments/fev-bench/). The writeup's figures are now served from the repo, so they render for logged-out readers. See [#61](https://github.com/TimeCopilot/foundationforecast/pull/61).
* **Example notebooks**: Every notebook starts with a `uv` install cell ([#55](https://github.com/TimeCopilot/foundationforecast/pull/55)), the family guides share one supported-weights table layout ([#59](https://github.com/TimeCopilot/foundationforecast/pull/59)), and the anomaly detection ([#58](https://github.com/TimeCopilot/foundationforecast/pull/58)) and finetuning ([#62](https://github.com/TimeCopilot/foundationforecast/pull/62)) notebooks keep their outputs.
* **README**: One logo per color scheme, served from the repo at matching sizes ([#52](https://github.com/TimeCopilot/foundationforecast/pull/52), [#53](https://github.com/TimeCopilot/foundationforecast/pull/53)), and a highlight for the GIFT-Eval replication.
* **`AGENTS.md`**: Guide for coding agents covering commits, releases and the test contract ([#46](https://github.com/TimeCopilot/foundationforecast/pull/46)).
