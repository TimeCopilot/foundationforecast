### Features

* **T0 gamma**: The [`T0`](https://docs.timecopilot.dev/foundationforecast/api/models/foundation/models/#foundationforecast.models.t0.T0) wrapper supports [`theforecastingcompany/t0-gamma`](https://huggingface.co/theforecastingcompany/t0-gamma) alongside t0-alpha and t0-beta. Quantile ranges are read from each checkpoint's `config.json`, so gamma keeps its 0.01–0.99 tails instead of inheriting alpha's 0.1–0.9 range from the repo name. See [#66](https://github.com/TimeCopilot/foundationforecast/pull/66).
* **T0 inference options**: Optional `trim_leading_missing`, `symmetric_averaging`, `clip_nonnegative`, `snap_integers`, and `cross_inference` pass through to `tfc-t0` 0.6 (all off by default for alpha/beta; the published t0-gamma scores enable them, including `cross_inference=64`).

### Tests

* **T0**: New tests for tail quantiles, inference-flag passthrough, and cross-series grouping; t0-gamma is included in the cross-model contract. See [#66](https://github.com/TimeCopilot/foundationforecast/pull/66).
* **Benchmark CI**: GIFT-Eval and fev-bench subsets add t0-gamma with leaderboard references and the notebook-aligned kwargs.

### Documentation

* **T0 family notebook**: [`t0-family` example notebook](../examples/t0-family.ipynb) compares alpha, beta, gamma, and gamma with benchmark settings. See [#66](https://github.com/TimeCopilot/foundationforecast/pull/66).
* **Model hub and README**: Document t0-gamma and the `tfc-t0[torch]>=0.6.0` requirement.

### Tooling

* **Dependencies**: Pin `tfc-t0[torch]>=0.6.0` (PyTorch moved into a `[torch]` extra in tfc-t0 0.6). Experiment lockfiles refreshed.
