### Features

* **Model weight cache**: All local weight-loading forecasters reuse loaded weights across repeated `forecast()` calls via a process-wide LRU cache on the base `Forecaster` (default `max_cached_models=1`). Configure with `set_max_cached_models()` or opt out per forecaster with `reuse_loaded_model=False`.
* **`clear_model_cache()`**: All forecasters expose `clear_model_cache()`; `FoundationForecast(clean_cache=True)` calls it after each model in multi-model runs to limit GPU memory use.
* **CodSpeed benchmarks** ([#23](https://github.com/TimeCopilot/foundationforecast/pull/23)): Add `pytest-codspeed` and a `benchmark` pytest marker (excluded from the default test run). Core benchmarks cover `maybe_infer_freq`, `TimeSeriesDataset`, `QuantileConverter`, and `SeasonalNaiveModel`; model benchmarks cover Chronos-Bolt, TimesFM 1.0, Toto, and Moirai 1.1. A dedicated `.github/workflows/codspeed.yml` workflow runs simulation benchmarks for core code and walltime/macro benchmarks for models in CI.
