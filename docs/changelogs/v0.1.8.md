### Features

* **T0 beta support**: The shared [`T0`](../api/models/foundation/models.md#foundationforecast.models.t0.T0) wrapper now works with [`theforecastingcompany/t0-beta`](https://huggingface.co/theforecastingcompany/t0-beta) (~256M). Register it in gift-eval `models.yaml`; GIFT-Eval CI still replicates `t0-alpha` until leaderboard results exist for beta.

    ```python
    import pandas as pd
    from foundationforecast.models.t0 import T0

    df = pd.read_csv(
        "https://timecopilot.s3.amazonaws.com/public/data/air_passengers.csv",
        parse_dates=["ds"],
    )
    model = T0(
        repo_id="theforecastingcompany/t0-beta",
        alias="t0-beta",
    )
    fcst = model.forecast(df, h=12, freq="D", quantiles=[0.1, 0.5, 0.9])
    assert "t0-beta" in fcst.columns
    ```

### Fixes

* **T0 / gift-eval CI**: Bump `tfc-t0` to `>=0.5.0` and call `T0Forecaster.predict(quantile_levels=...)` instead of the removed `quantiles=` kwarg. Fixes gift-eval Modal runs after PyPI resolved `tfc-t0` 0.5.0 alongside the t0-beta release.

### Dependencies

* Bumped `tfc-t0` from `>=0.2.3` to `>=0.5.0` (required for t0-beta; still supports t0-alpha).
* Replaced `timecopilot-granite-tsfm` with `granite-tsfm>=0.3.9` for Granite PatchTST-FM r2 overlapping-patch inference (`n_patch=1023`, `patch_stride=8`).
