### Fixes

* **Quantile column suffixes**: Output columns use minimal decimal text for `100 × quantile` (for example `0.57` → `{alias}-q-57`, `0.151` → `{alias}-q-15.1`, level-derived `0.975` → `{alias}-q-97.5` during conversion) instead of `int(100 × quantile)` or rounded centile suffixes, which collided for multi-`level` requests (for example `level=[95, 97]`) or truncated float noise (`Chronos-q-56` for `0.57`).
* **`quantiles=` validation**: User-provided `quantiles` may have up to three decimal places with unique suffixes; duplicate mappings raise instead of silently overwriting columns in GluonTS paths.
* **`level=` validation**: Confidence levels must be **integer** percents (fractional `level` values are rejected).
