### Fixes

* **Quantile column suffixes**: Output columns use `round(100 × quantile)` centile suffixes (for example `0.57` → `{alias}-q-57`) instead of `int(100 × quantile)`, which truncated float noise to the wrong suffix (for example `Chronos-q-56`).
* **Centile-only `quantiles`**: User-provided `quantiles` must be centiles in `(0, 1)` with unique output suffixes; duplicate centile mappings raise instead of silently overwriting columns in GluonTS paths.
