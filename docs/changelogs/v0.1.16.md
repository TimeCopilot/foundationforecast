### Features

* **TimeH2O**: The [`TimeH2O`](https://docs.timecopilot.dev/foundationforecast/api/models/foundation/models/#foundationforecast.models.timeh2o.TimeH2O) wrapper supports H2O.ai's [`timeh2o-v1`](https://huggingface.co/h2oai/timeh2o-v1) and [`timeh2o-v1-tiny`](https://huggingface.co/h2oai/timeh2o-v1-tiny) checkpoints via `h2ofm>=0.43.0` (Python 3.12+). Native known-future covariates (`X_df`) on `timeh2o-v1`, including categorical columns encoded by `h2ofm`; arbitrary `level` / `quantiles` (levels outside the trained 0.1–0.9 grid use Gaussian-tail extrapolation); and `clip_nonnegative` / `snap_integer` options matching the published benchmark runs. The checkpoints are gated and released under a non-commercial license. See [#77](https://github.com/TimeCopilot/foundationforecast/pull/77).

### Tests

* **TimeH2O**: Mocked tests for quantile mapping, context truncation, covariate alignment, categorical covariates and option passthrough; a live smoke test on `timeh2o-v1-tiny`; and cross-model contract coverage for both checkpoints on Python 3.12+. See [#77](https://github.com/TimeCopilot/foundationforecast/pull/77).
* **Benchmark CI**: GIFT-Eval (`m4_weekly`) and fev-bench (`epf_pjm`, `entsoe_1H`) subsets add `timeh2o-v1`, with the settings of the official submissions and leaderboard references. See [#77](https://github.com/TimeCopilot/foundationforecast/pull/77).

### Documentation

* **TimeH2O family notebook**: [`timeh2o-family` example notebook](../examples/timeh2o-family.ipynb) compares both checkpoints and the benchmark settings, and shows known-future covariates on electricity prices. See [#77](https://github.com/TimeCopilot/foundationforecast/pull/77).
* **Model hub and README**: Document TimeH2O checkpoints, Python 3.12+ requirement, gated non-commercial license and native exog support; add H2O.ai/TimeH2O to the supported-models table.

### Tooling

* **Dependencies**: Add `h2ofm>=0.43.0` (Python 3.12+) and require `timecopilot-timesfm>=0.4.1`, which drops the `safetensors<0.6` cap that conflicted with `h2ofm`.
* **Benchmark harnesses**: Models can set `python` in `models.yaml`; GIFT-Eval and fev-bench Modal runs dispatch them to a Python 3.12 image while other models stay on 3.11. Experiment lockfiles refreshed.
