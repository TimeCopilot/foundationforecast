### Features

* **Simons**: The [`Simons`](https://docs.timecopilot.dev/foundationforecast/api/models/foundation/models/#foundationforecast.models.simons.Simons) wrapper supports Abel AI Lab's [`Simons-25M/60M/178M/297M`](https://huggingface.co/collections/abel-lab/simons-1-6ae3d4ce9705938e293c52dd) checkpoints via `timecopilot-simons>=0.1.0`. Nine native quantile knots (0.1–0.9) with linear interpolation and edge clamping, the 0.5 quantile as the point forecast, and native known-future covariates (`X_df`). A local `repo_id` is a directory with `config.json` and `model.safetensors`. See [#113](https://github.com/TimeCopilot/foundationforecast/pull/113).
* **Adaptive conformal inference**: New [`ACI`](https://docs.timecopilot.dev/foundationforecast/api/core/conformal/#foundationforecast.core.conformal_aci.ACI) method for [`ConformalIntervals`](https://docs.timecopilot.dev/foundationforecast/api/core/conformal/#foundationforecast.core.conformal.ConformalIntervals), replaying the miscoverage update from [Gibbs and Candès (2021)](https://arxiv.org/abs/2106.00170). For each series, horizon step, and level it updates `alpha` from revealed absolute errors and reads the interval from the empirical quantile of those errors. The replay is stateless: nothing is stored between `forecast()` calls. `ACI` is exported from `foundationforecast`. See [#112](https://github.com/TimeCopilot/foundationforecast/pull/112).

    ```python
    from foundationforecast import ACI, ConformalIntervals
    from foundationforecast.models import Chronos

    model = Chronos(
        repo_id="amazon/chronos-bolt-tiny",
        alias="Chronos-Bolt",
        prediction_intervals=ConformalIntervals(n_windows=20, method=ACI(gamma=0.005)),
    )
    ```

* **`ACI` options**: `gamma` (default `0.01`) is the adaptation rate. `ncal` seeds the score distribution before alpha updates (`None` uses half the windows). `rolling=True` keeps only the latest `ncal` revealed scores. Intervals are symmetric absolute errors. Alpha is not clipped: `alpha <= 0` is an unbounded interval and `alpha >= 1` is empty, and either case emits a `UserWarning`.

### Tests

* **Simons**: Covariate-shape tests, a real `Simons-25M` forecast, and cross-model contract coverage, including a local checkpoint. Quantile checks allow equal values where a requested tail is clamped to 0.1 or 0.9. See [#113](https://github.com/TimeCopilot/foundationforecast/pull/113).
* **Benchmark CI**: GIFT-Eval runs `Simons-297M` on `m4_weekly` (short). fev-bench runs `Simons-297M` on `epf_pjm` and `entsoe_1H` against `simons-297m.csv`.
* **ACI**: Causal replay, delayed feedback, no cross-call state, extreme-interval warnings, and a `test_models.py` contract test. See [#112](https://github.com/TimeCopilot/foundationforecast/pull/112).
