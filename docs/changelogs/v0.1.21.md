### Features

* **CIProto**: The [`CIProto`](https://docs.timecopilot.dev/foundationforecast/api/models/foundation/models/#foundationforecast.models.ciproto.CIProto) wrapper supports Continuous Intelligence's [`ContinuousIntelligence/ci-proto`](https://huggingface.co/ContinuousIntelligence/ci-proto), a ~167M-parameter zero-shot probabilistic forecaster with a very long context (16,384 steps on the standard checkpoint; longer histories switch to the long checkpoint automatically). It returns nine native quantiles between 0.1 and 0.9 and accepts known-future covariates through `X_df`. See [#99](https://github.com/TimeCopilot/foundationforecast/pull/99).

    ```python
    import pandas as pd

    from foundationforecast import FoundationForecast
    from foundationforecast.models import CIProto

    DATA = "https://timecopilot.s3.amazonaws.com/public/data/electricity_price"
    df = pd.read_parquet(f"{DATA}/train.parquet")
    X_df = pd.read_parquet(f"{DATA}/futr_exog.parquet")

    ff = FoundationForecast(models=[CIProto()])
    fcst_df = ff.forecast(df=df, h=24, X_df=X_df, level=[80])
    ```

* **Optional `ci-proto` extra**: CIProto needs the `continuousintelligence` package, installed only with `foundationforecast[ci-proto]`. It is not a core dependency, `foundationforecast.models` imports without it, and constructing the model without the extra raises an `ImportError` with the install command. `foundationforecast.models.ciproto.is_ciproto_available()` reports whether the extra is installed.
* **Conformal finite-sample intervals**: New opt-in `method="conformal_error_finite_sample"` for [`ConformalIntervals`](https://docs.timecopilot.dev/foundationforecast/api/conformal/#foundationforecast.core.conformal.ConformalIntervals) uses the exact `ceil((n + 1) * level / 100)`-th absolute-error order statistic, without interpolation. When the rank exceeds the calibration sample size the bounds are infinite. Existing methods and defaults are unchanged. See [#92](https://github.com/TimeCopilot/foundationforecast/pull/92).

### Fixes

* **Post-publish release smoke test**: The `After publishing test` step now runs outside the repo checkout, pins `foundationforecast==<released version>`, and retries until the PyPI index serves it, so it checks the published wheel instead of the repo source. See [#98](https://github.com/TimeCopilot/foundationforecast/pull/98).

### Tests

* **CIProto**: Mocked-model tests in `tests/models/test_ciproto.py` (loader, cache key, batching and left padding, timestamps, native future covariates, `level` and `quantiles`, install hint). `CIProto` joins the `test_models.py` parametrization whenever the `ci-proto` extra is installed. The example notebook was executed on a Modal A10G with the real checkpoint.
* **Conformal finite-sample**: Contract test parametrized over every registered model and an executed M4 Hourly rolling-origin comparison of coverage, width, and finite intervals.
