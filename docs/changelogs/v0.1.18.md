### Features

* **Conformal prediction intervals**: Opt-in [`ConformalIntervals`](https://docs.timecopilot.dev/foundationforecast/api/core/conformal/#foundationforecast.core.conformal.ConformalIntervals) via `prediction_intervals=` on every model constructor. When `forecast()` or `cross_validation()` is called with `level` / `quantiles`, FoundationForecast calibrates those intervals from per-series cross-validation absolute errors on the **point forecast**, instead of the model's native quantile head. The point forecast is unchanged. See [#83](https://github.com/TimeCopilot/foundationforecast/pull/83).

    ```python
    import pandas as pd

    from foundationforecast import ConformalIntervals, FoundationForecast
    from foundationforecast.models import Chronos, Tafsut

    df = pd.read_csv(
        "https://timecopilot.s3.amazonaws.com/public/data/air_passengers.csv",
        parse_dates=["ds"],
    )

    pi = ConformalIntervals(n_windows=3, method="conformal_distribution")
    ff = FoundationForecast(
        models=[
            Tafsut(prediction_intervals=pi),
            Chronos(
                repo_id="amazon/chronos-bolt-tiny",
                alias="Chronos-Bolt",
                prediction_intervals=pi,
            ),
        ]
    )
    fcst = ff.forecast(df=df, h=12, freq="MS", level=[80, 95])
    ```

* **Calibration**: Panel `cross_validation` of the point forecast (`n_windows`, `step_size` defaulting to `h`). Two methods: `conformal_distribution` (default; synthetic outcomes around the point) and `conformal_error` (symmetric error quantile). Windows are ranked **per series**, so staggered histories do not mix residuals. Median-only `quantiles=[0.5]` skips calibration. `detect_anomalies` stays point-only.
